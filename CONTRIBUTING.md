# Разработка

Нужны Python 3.12+ и uv. Все проверки работают без личного Moodle, Telegram и Codex.

```sh
uv sync --locked --python 3.12
uv run playwright install chromium
uv run pytest -q
uv run ruff check src tests scripts
```

Тесты используют временные каталоги и вымышленный локальный Moodle. Настоящие запросы к Codex включаются только явным `MENTOR_LIVE_CODEX=1` и расходуют лимит аккаунта. На Linux перед браузерными тестами может понадобиться `uv run playwright install --with-deps chromium`.

Не прикладывайте к issue или PR `.env`, `cred.txt`, базу SQLite, `data/`, браузерный профиль, cookies, HAR, трассировки и снимки страниц с персональными данными. Описывайте ошибку кодом и этапом из `/status`, типом вопроса и обезличенным примером. Для изменения селекторов сначала воспроизведите проблему на синтетической странице.

Перед коммитом добавляйте только нужные исходники и запускайте проверку содержимого индекса:

```sh
uv run python scripts/check_publication.py
git diff --cached --stat
```

Проверка читает только разрешённые исходные файлы из индекса Git. Запрещённые пути отклоняются до чтения содержимого. Это дополнительная проверка известных форматов, а не гарантия нахождения любого произвольного секрета. CI повторяет её и браузерные тесты на Linux, macOS и Windows.
