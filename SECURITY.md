# Конфиденциальность

Настоящие секреты хранятся только локально: `.env`, `cred.txt`, `data/` и профиль браузера. Они исключены из Git. Мастер настройки скрывает ввод и не открывает уже существующий `cred.txt`; его читает только `auth.py` во время авторизации готового приложения.

LLM получает условие вопроса, локальные идентификаторы вариантов и при необходимости изображение блока вопроса. Вопросы могут обрабатываться облачным сервисом модели; для полностью локальной обработки нужен локальный inference-сервер. Изменение темы Moodle требует проверки границ безопасной области снимка.

Приложение не обходит ограничения платформы. Обязательное одноразовое подтверждение завершения связано с конкретной попыткой; ошибки связи, перезапуск и пауза отзывают разрешение. Истечение времени на стороне Moodle может закрыть попытку независимо от приложения.

Если секрет попал в Git или issue, немедленно отзовите/замените его у соответствующего провайдера. Не публикуйте секрет повторно в сообщении об ошибке. Для сообщения об уязвимости используйте приватный канал GitHub Security Advisories, если он доступен в репозитории.
